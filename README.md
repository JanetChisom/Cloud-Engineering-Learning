# My Cloud Engineering Journey

## Why Cloud Engineering?

Before discovering Cloud Engineering, I explored different areas of technology, including software development, networking, and other aspects of tech. I tried different paths, but none of them felt like something I truly connected with.

That changed during my IT experience at NigComSat.

I worked in the Broadcast Department, where I got the opportunity to see and work around an environment managing more than 300 servers. Being exposed to that kind of infrastructure made something click for me.

I enjoyed seeing how the systems were managed, how the servers supported the operations, and how important reliable infrastructure is to an organization.

That experience made me realize that this is the kind of work I want to do.

**I want to become a Cloud Engineer.**

This repository is where I document that journey — what I learn, what I build, the challenges I face, the mistakes I make, and the progress I make along the way.

---

## My Learning Journey

I initially tried to learn technology on my own, but I found it difficult to stay on track and understand how everything connected.

That was one of the reasons I decided to join AltSchool Africa, where I could have a more structured learning environment and learn alongside other people.

So far, I have explored and learned different areas of technology, including:

- HTML
- CSS
- JavaScript
- Linux
- Git & GitHub
- And other foundational technologies

Although I started with software development and explored different areas of tech, my goal became clearer after my IT experience. I now want to build on the foundation I have gained and focus my learning on Cloud Engineering.

## My Cloud Engineering Learning Journey

I started my Cloud Engineering journey by first understanding what Cloud Engineering is, what Cloud Engineers do, and the different paths I can take within the field.

From there, we moved into practical concepts, including Virtual Machines, where I began getting more familiar with virtualization and working with different operating system environments.

We are currently learning Linux. So far, I have been learning about processes, process management, and other Linux fundamentals. I am also getting more comfortable working with the command line and understanding how systems work behind the scenes.

I am documenting this journey here because I want to be able to look back and see where I started, what I have learned, the challenges I faced, and how far I have come.
